# מחשבון גבייה

קובץ אחד, בלי התקנה ובלי שרת. מחשב חיוב לתקופה לפי תעריפי מגורים ותכנית,
כולל תקופות מילואים ותשלומים שבוצעו.

**המאגר הזה מכיל את המחשבון בלבד.** אין בו נתונים של אף אדם, אין שמות
מושבים ואין רשימת משתתפים — רק מנוע החישוב והמסך שמפעיל אותו.

## מה יש כאן

`index.html` — המחשבון. הכול מוטמע בתוכו: העיצוב, הקוד, וכללי החישוב.
אפשר לפתוח אותו מכל דפדפן, גם בלי אינטרנט.

## למה מאגר נפרד

המערכת עצמה — זו שמחזיקה משתתפים, תשלומים ומסמכים — יושבת במאגר פרטי.
המחשבון הוא החלק היחיד שאפשר למסור לכל אחד, ולכן הוא מופרד.

## עדכון

המחשבון נבנה מתוך קוד המערכת (`npm run build:calculator`), כדי שיריץ את
**אותו מנוע חישוב** ולא נוסחה מקבילה. מספר שיוצא כאן הוא המספר שייצא גם
בחיוב האמיתי באותם נתונים.

כשכלל חישוב משתנה, צריך לבנות מחדש ולהחליף כאן את `index.html`. בתחתית
המחשבון מופיעה חותמת תאריך — זה מה שמאפשר לזהות עותק ישן.
